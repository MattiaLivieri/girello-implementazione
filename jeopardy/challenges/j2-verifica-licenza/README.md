# J2 Verifica licenza

La challenge riguarda la ricostruzione della logica di un verificatore Java
a partire dal bytecode distribuito. L'analisi statica deve essere sufficiente;
l'esecuzione del verificatore è facoltativa.

## Stato

Specifica iniziale. Codice Java, build, pacchetto e collaudo non ancora realizzati.

## Materiali previsti

- Sorgenti del verificatore e build con destinazione Java 17, senza preview.
- JAR senza dipendenze applicative esterne, incluso in uno ZIP con istruzioni.
- Checksum degli artefatti e istruzioni per gli strumenti offline.
- Controlli di ricostruzione statica e di gestione degli input validi e non validi.

Formato e normalizzazione del codice accettato verranno definiti senza
ambiguità nell'implementazione e nelle istruzioni. Lo studente utilizza il
JAR sul proprio PC; non serve un runtime J2 sul Master.

La soluzione e i valori canonici rimangono nei materiali riservati degli autori.
